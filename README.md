# RealStats Baccarat (Android 14 - Kotlin)

Ứng dụng thống kê xác suất thực tế dạng cửa sổ nổi (Floating Overlay) dành cho Android 14 (API 34).

## Cách mở và xuất file APK trên Android Studio
1. Giải nén tệp `RealStatsBaccarat_Android14.zip`.
2. Mở **Android Studio** -> chọn **Open** -> trỏ tới thư mục `RealStatsBaccarat`.
3. Chờ Gradle đồng bộ xong, chọn menu **Build** -> **Build Bundle(s) / APK(s)** -> **Build APK(s)**.
4. Chép tệp `app-debug.apk` vào điện thoại Android 14 và cài đặt.

## Mở khóa quyền cửa sổ nổi trên Android 14
1. Khi bấm **BẬT CỬA SỔ DỮ LIỆU NỔI**, nếu nút gạt quyền bị làm mờ (*Cài đặt bị hạn chế*), hãy mở **Cài đặt** -> **Ứng dụng** -> **RealStats Baccarat**.
2. Bấm dấu **3 chấm** góc trên bên phải -> chọn **Cho phép cài đặt bị hạn chế**.
3. Quay lại bật quyền **Hiển thị trên ứng dụng khác**.
